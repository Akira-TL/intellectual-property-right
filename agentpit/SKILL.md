# 魔镜智能体技能说明

## 使用场景

- 发布前风险预判：输入文案、海报描述、短视频脚本，输出 red/orange/yellow/green 分级风险。
- 发布后监控告警：输入疑似链接和上下文，输出告警优先级与处置建议。
- 维权策略建议：输入传播规模、历史链接证据，输出下架或诉讼路径建议。

## 输出约束

- 必须给出风险颜色：red / orange / yellow / green。
- 必须给出置信度：0.0 - 1.0。
- 必须包含法律依据摘要：商标、著作权、不正当竞争。
- 必须引用参考判例或类案逻辑。
- 必须给出下一步动作建议。
- 禁止使用绝对化结论（例如“一定侵权”“100%侵权”）。

## 建议提示模板

请根据输入内容输出结构化风险评估，包含：

1. riskColor
2. confidence
3. legalBasis[]
4. precedents[]
5. recommendation
6. disclaimer（说明结果为风险评估，不构成法律意见）
