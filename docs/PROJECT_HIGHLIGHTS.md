# 项目亮点

## 亮点 1：把法务前置到创意发布前

- 传统流程往往在上线后才发现风险，代价高、反应慢。
- 本产品将风险评估前移到创意产出阶段，帮助团队在“发布前”完成筛查。

## 亮点 2：结果可解释，不是黑盒打分

- 每次评估不仅输出风险等级，还给出：
- 置信度
- 法律依据摘要
- 参考判例
- 建议动作
- 便于运营、法务、管理层在同一页面完成决策沟通。

## 亮点 3：监控与告警闭环

- 发布后通过鹰眼模式持续巡检，发现疑似侵权后即时告警。
- 从“偶然发现”升级为“系统发现”。

## 亮点 4：固证与策略建议一体化

- 不是只提醒风险，而是继续向后衔接：
- 证据包结构化
- 投诉文书模板化
- 策略路径对比化（快速下架 vs 诉讼准备）

## 亮点 5：兼顾黑客松展示与赛后扩展

- 当前版本用前端 Demo 完整呈现业务价值。
- 数据结构采用 schema-first 设计，赛后可平滑接入后端服务。
