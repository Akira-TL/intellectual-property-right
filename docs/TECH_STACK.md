# 技术栈说明（宣传口径）

## 说明

本页用于路演宣传时展示“完整产品能力”，并与当前 Demo 实现区分。

## 一、目标态技术栈（产品化版本）

### 1. 多模态 AI 识别层

- 多模态大模型：文本、图像、音频、视频联合理解。
- 检索与召回：向量数据库 + 相似度检索。
- 生成式对抗检测：识别换脸、洗稿、局部改写等变体。

### 2. 法律规则引擎层

- 法律规则 DSL：将商标法、著作权法、不正当竞争规则参数化。
- 判例知识图谱：按案由、争点、裁判观点组织检索。
- 审计与解释链路：保留判定路径、阈值命中和证据引用。

### 3. 监控与固证平台层

- 分布式任务调度：多平台监控任务编排。
- 证据仓与存证服务：时间戳、哈希、区块链存证。
- 文书引擎：生成多平台投诉模板与诉讼材料草案。

### 4. 产品与企业集成层

- SaaS 多租户与权限模型。
- 企业 SSO、审计日志、报表系统。
- 与 CRM、法务工单、风控系统 API 集成。

## 二、当前 Demo 实现栈（路演版本）

- React + TypeScript + Vite
- Material UI 组件系统
- 本地 mock 数据驱动
- 前端状态管理模拟真实流程

## 三、路演表达建议

- 对评委讲“目标态技术栈”时，强调产品可扩展性与工程可落地性。
- 演示时落回“Demo 实现栈”，强调当前版本已完整呈现核心业务闭环。
